## 1. Алгоритм и блок-схема

### Алгоритм:
1. Начало.
2. Объявить переменные:
   * x — первый аргумент.
   * y — второй аргумент.
   * z — третий аргумент.
   * term1 — первое слагаемое.
   * term2 — второе слагаемое.
   * term3 — третье слагаемое (дробь).
   * b — итоговый результат.
3. Присвоить значения переменным x, y, z согласно условию.
4. Вычислить term1 = y ^ (кубический корень из |x|).
5. Вычислить term2 = cos³(y).
6. Вычислить term3 как дробь: числитель / знаменатель.
7. Вычислить итоговое значение b = term1 + term2 - term3.
8. Вывести исходные данные и результат b.
9. Конец.
